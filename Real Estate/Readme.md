# Real Estate Sales Forecasting – Dublin

## Project Overview

This project focuses on predictive analytics for residential property sales forecasting using Dublin housing market data.

The objective was to analyze property characteristics and predict whether a property is likely to be purchased based on factors such as:

* Location
* Property size
* BER rating
* Renovation requirement
* Total square footage
* Price per square foot

The project involved end-to-end data preprocessing, exploratory analysis, feature engineering, visualization, and machine learning model evaluation.

## Key Tasks Performed

### Data Cleaning & Preprocessing

* Handled missing values and inconsistent formats
* Standardized square footage ranges
* Encoded categorical variables
* Removed outliers using IQR and statistical filtering

### Exploratory Data Analysis

* Built correlation heatmaps
* Created scatter plots for property size vs. pricing trends
* Analyzed feature relationships affecting buying decisions

### Machine Learning Models

Tested multiple predictive models including:

* Linear Regression
* Logistic Regression
* Support Vector Machine (SVM)
* Decision Tree
* Random Forest
* Naive Bayes
* Voting Classifier

---

## Key Insights

* Random Forest achieved the best performance with ~76% prediction accuracy.
* Property size and total square footage showed strong positive correlation with pricing trends.
* Data preprocessing and outlier removal significantly improved model performance.
